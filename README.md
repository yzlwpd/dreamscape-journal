# 梦境映像 Dreamscape Journal

梦境记录、AI辅助阅读与情绪可视化课程作品。支持记录原始片段、确认补全草稿、查看情绪证据与文献、选择视觉画风，以及回看历史记录。

**创作方式：**选题及体验后的修改反馈由杨政提供，代码由Codex辅助完成。本仓库展示作品及AI协作过程，不代表作者独立手写实现全部功能。个人贡献说明见[项目介绍](docs/project-case-study.md)。

## 免费示例体验

需要Node.js 22或兼容版本。在仓库根目录依次执行：

```sh
npm ci
npm run build
npm run demo
```

浏览器打开 http://127.0.0.1:4173 。保持服务终端运行。

示例模式不需要MySQL或API密钥，不调用付费AI服务；分析使用示例规则及预设数据，生图展示预置图片。新增演示记录保存在本机data/demo.json，不会提交到仓库。不要在示例中输入私人信息。

## 正式模式

1. 复制.env.example为.env，在本机填写MySQL连接参数及所需API密钥。
2. 执行npm run db:init，仅初始化配置指定的项目库；数据库账户须有相应权限。
3. 执行npm run build，再执行npm start。
4. 浏览器访问本机地址，注册账号后操作。

正式模式与示例模式分开选择，不在数据库失败时自动退回示例。不要同时占用同一端口。

文本服务使用DeepSeek接口，生图使用百炼异步任务接口，文献使用Europe PMC检索接口。模型权限、区域、可用性及费用需自行向服务提供方核验；本次整理未使用付费API完成端到端验收。密钥由后端读取，不放入前端或GitHub。

## 功能及边界

- 日记：原始记录、可选补全、用户确认、收藏、删除、个人JSON导出。
- AI辅助阅读：情绪与意象、原文引文、现实背景关联、文献引用编号过滤。
- 视觉创作：画风与文本来源选择、异步任务轮询、生成图片保存代码。
- 情绪洞察：单篇画像、梦中与醒后对照、场景顺序、历史矩阵、时间筛选与主题跳转。
- 账户：注册、登录、昵称与密码修改、会话及跨用户访问限制。

真实模型输出质量和真实生图成功尚未在本次发布检查中验证，不提供准确率或心理效果结论。AI补全不能恢复真实记忆，梦境解读与情绪可视化不能用于心理诊断。

## 本机运行限制

会话与任务锁保存在进程内，服务重启后需重新登录。本作品只监听本机地址，未作为公网生产服务验收；公开部署还需要处理HTTPS、持久会话、任务持久化和负载验证。
